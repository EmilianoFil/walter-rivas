## Design Context

### Users
Walter Rivas — usuario único. Uso personal diario para gestionar activos propios: casa quinta, departamentos, obras, empresa, flota. Contexto relajado pero recurrente, desde el celular. No hay audiencia externa ni necesidad de impresionar; la prioridad es legibilidad y velocidad de lectura.

### Brand Personality
Personal, ordenado, directo. Como un buen cuaderno de cuentas bien encuadernado — no corporativo, no tech-startup, no sobre-diseñado.

### Aesthetic Direction
**Warm-functional.** Modo claro. Colores cálidos (OKLCH tintados hacia el acento rojo, hue 30) en lugar de grises fríos. El acento rojo `oklch(54% 0.22 25)` ≈ `#e63946` se mantiene pero se usa escasamente.

**Tipografía:** Chivo (Omnibus-Type, Argentina). Grotesca limpia y funcional, con figuras tabulares para montos (`font-variant-numeric: tabular-nums`). Una sola familia, múltiples pesos.

**Paleta slate cálida** (override en @theme):
- slate-50:  `oklch(97.8% 0.005 30)` — fondo principal
- slate-900: `oklch(18.5% 0.01 30)` — sidebar / texto fuerte

### Design Principles
1. **Funcional antes que decorativo** — cada elemento visual tiene que justificar su presencia
2. **Legibilidad financiera** — los montos se leen de un vistazo; tabular nums, jerarquía clara
3. **Sin redundancia** — si un número ya aparece, no repetirlo en otro formato decorativo
4. **Escasez de acento** — el rojo trabaja porque es raro; no usarlo como fondo principal
5. **Sin patrones prohibidos** — nada de border-left stripe, gradient text, gradient hero metric, glassmorphism
